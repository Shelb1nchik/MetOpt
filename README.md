Репозиторий с решениями задач по дисциплине «Методы оптимизации».

## О репозитории

Здесь собраны выполненные задания по курсу. Каждая задача лежит в отдельной папке и оформлена в виде Jupyter-ноутбука с пояснениями, формулами и кодом.

## Технологии

- **Язык:** Python 3
- **Библиотеки:** numpy, scipy
- **Среда:** Google Colab / Jupyter Notebook
- **Оформление:** Markdown + LaTeX для формул

## Формат отчёта

Каждая задача представлена отдельным `.ipynb`-файлом, в котором:

1. Условие задачи.
2. Формулы в LaTeX.
3. Код решения на Python.
4. Вывод результатов.
5. Проверка.
