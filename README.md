## Задача 1. Линейное программирование

**Вариант 15**

Прямая задача:

$$\max z = 3x_1 - x_2 + 2x_3 + x_4$$

$$
\begin{cases}
x_1 - x_2 + 2x_3 + x_4 \le 8\\
3x_2 + x_3 \le 7\\
4x_1 + x_2 + 3x_3 + 2x_4 \le 15\\
x_1, x_2, x_3, x_4 \ge 0
\end{cases}
$$

Двойственная задача:

$$\min w = 8y_1 + 7y_2 + 15y_3$$

$$
\begin{cases}
y_1 + 4y_3 \ge 3\\
-y_1 + 3y_2 + y_3 \ge -1\\
2y_1 + y_2 + 3y_3 \ge 2\\
y_1 + 2y_3 \ge 1\\
y_1, y_2, y_3 \ge 0
\end{cases}
$$

**Ответ:**

$$x = (3.75,\ 0,\ 0,\ 0), \quad z_{\max} = 11.25$$
$$y = (0,\ 0,\ 0.75), \quad w_{\min} = 11.25$$
