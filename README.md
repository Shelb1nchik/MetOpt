## Задача 1. Линейное программирование

### Вариант 15

**Прямая задача:**

$$\max z = 3x_1 - x_2 + 2x_3 + x_4$$

при ограничениях:

$$
\begin{cases}
x_1 - x_2 + 2x_3 + x_4 \le 8\\
3x_2 + x_3 \le 7\\
4x_1 + x_2 + 3x_3 + 2x_4 \le 15\\
x_1, x_2, x_3, x_4 \ge 0
\end{cases}
$$

Матрицы:

$$c = (3,\,-1,\,2,\,1), \quad
A = \begin{pmatrix}
1 & -1 & 2 & 1\\
0 & 3 & 1 & 0\\
4 & 1 & 3 & 2
\end{pmatrix}, \quad
b = (8,\,7,\,15)$$

**Двойственная задача:**

$$\min w = 8y_1 + 7y_2 + 15y_3$$

при ограничениях:

$$
\begin{cases}
y_1 + 4y_3 \ge 3\\
-y_1 + 3y_2 + y_3 \ge -1\\
2y_1 + y_2 + 3y_3 \ge 2\\
y_1 + 2y_3 \ge 1\\
y_1, y_2, y_3 \ge 0
\end{cases}
$$

**Ответ:**

Оптимальное решение прямой задачи:

$$x_1 = 3.75,\quad x_2 = 0,\quad x_3 = 0,\quad x_4 = 0$$

$$z_{\max} = 3 \cdot 3.75 - 1 \cdot 0 + 2 \cdot 0 + 1 \cdot 0 = 11.25$$

Оптимальное решение двойственной задачи:

$$y_1 = 0,\quad y_2 = 0,\quad y_3 = 0.75$$

$$w_{\min} = 8 \cdot 0 + 7 \cdot 0 + 15 \cdot 0.75 = 11.25$$

Проверка по теореме двойственности:

$$z_{\max} = w_{\min} = 11.25$$
